# AD-HOST V26 0.4.0 使用说明

本版面向 STM32 V1.0.13 (V26)、FPGA ID ADFC / VERSION 0200，不能用旧固件直接替代测试。协议能力依据随源码附带的 V26 文档；硬件联调仍须在实际板卡上完成。

## 开始使用

便携版完整解压后运行 AD-HOST.exe。源码版安装 Python 3.10+（含 Tcl/Tk），执行 `python -m pip install -r requirements.txt`，再执行 `python run.py`。

1. 输入 IP/端口（默认 192.168.3.178:11235），选择保存目录，点击连接。软件依次检查 VER、FST、TST。
2. 选择记录长度按“采样时间 ms”或“采样点数”。时间为 1–200 ms，点数为 1–20000000 对；一对是电压、电流各一个样本。
3. 设置前触发百分比。记录总长度含前后触发；后触发自动为 100%-前触发。100% 前触发记录不包含触发样本。
4. 选择手动/自动阈值触发。自动模式至少启用一个通道；两路同时启用时任一路满足即触发。
5. 点击“准备采集”，软件发送完整 CFG、核对 TST 后再 ARM。单独“应用配置”不会启动。
6. 手动模式：等“手动触发”按钮可用后点击。自动模式：等待阈值成立，不需要 FORCE。
7. 完成后软件自动读取并保存。切换“记录与波形”，点击“打开最近记录”。

## 阈值和示波器差异

- 电压/电流阈值都输入 0–4095 的 ADC 原始码，可选 ≥、>、=、≤、<。
- 电压图沿用已确认的 `(ADC×2/4096−1)×6 V`。电流尚无标定，显示原始值，不能把阈值当成 A。
- 当前值比较，不支持边沿、迟滞、两路 AND、脉宽、绝对值触发；严格相等没有容差。
- 自动阈值模式会一直等条件，不会像某些示波器 Auto 模式那样在超时后自行强制触发。
- 每次 ARM 一条记录，GET 期间不同时开始下一条记录，不是无死区连续采样。

## 重复记录

勾选“重复自动记录”，选择自动模式和组间隔（0–600000 ms，默认 1000）。每条保存后，软件等设备 GAP_LEFT_MS=0、READY 且无占用，再开始下一条。这个间隔从上一组 RELEASE 完成起算。

“停止后续记录”让当前条继续完成，只停止后续 ARM。“取消当前采集”会取消当前条并停止重复。缺少组间隔回读字段时不会启用重复采集。

## 取消、断线和已有记录

- 未完成：按设备状态发 ABORT。若取消瞬间恰好完成，会重新查询并在允许时 RELEASE。
- 已完成但不想读取：在“记录与波形”点击“丢弃设备已有记录”。被丢弃的板端记录无法再 GET。
- 正在 GET：取消通过关闭 TCP 实现，不向数据流插入 ABORT。未完成的部分数据保留为 `.partial.hex`。
- ARM 返回失败也可能已经执行：本条锁存配置标为未知，需按设备状态取消或读取，不沿用上一条设置。
- 命令超时：不自动重发 ARM/FORCE，关闭连接后需重连检查。设备可能已执行原命令。
- 等触发时断线，板卡可能仍在采集。重连后可取消或读取完成记录；不会自动 FINIT/重 ARM。
- 重连的活动记录可能没有完整锁存配置信息，软件明确标为未知，不使用“下一条 MODE”推断本条模式，因此可能不提供 FORCE。可取消后重新配置采集。

普通命令回复超时 5 秒；GET 无进度超时默认 30 秒，可在连接前于“设备诊断”调整。持续收到数据不会因达到固定总时长而中断；等待阈值没有自动超时。

## 保存和绘图

每组保存 `.hex` 与同名 `.hex.json`，请一起保留。HEX 只有 A/B ADC 正文，JSON 包含配置、完成时状态、触发位置/原因、长度和写入结果。收满正文、尾标志正确且文件关闭落盘后，才显示成功。

V26 绘图使用 `t=(i−ACTIVE_PRE)/RATE`：触发前负时间，触发后正时间。纵轴电压 V、电流原始计数。没有 JSON 的旧文件从记录起点计时，并提示触发位置未知。当前概览保留两个通道的峰谷，放大后按原始采样点重绘；保存图片保存当前视图。

两通道 V26 数据均检查 12 位范围；不完整记录和矛盾元数据会明确报错，不静默绘制成正常记录。离线读取源文件上限仍为 1 GiB；V26 单次最大 HEX 为 160 MB。

## 诊断指令

所有查询和控制通过同一个串行调度器，最多一条请求等待回复，GET 中暂停所有查询。单条 ASCII 正文不超过 127 字节，软件追加 CR。

支持 VER/FST/TST/FREG、完整 CFG/ACQ 十参数，以及受状态检查的 ARM/FORCE/ABORT/RELEASE/GET/CLEAR_EVENTS/FINIT。调试框中的 ACQ 等价执行“CFG→TST 核对→ARM”，保留相同主机保护。单参数配置请使用图形设置或完整 CFG；不提供任意二进制透传。

FINIT/CLEAR_EVENTS 不是正常采集步骤，不会被软件用来强行结束正在等待的采集。状态、原始回复、错误和近期操作在“设备诊断”中显示。

## 本机模拟与测试

运行 `python tools/v26_simulator.py --port 11235 --mbps 6`，上位机连接 127.0.0.1:11235，可验证主机流程。模拟器自动条件会在数次查询后成立；波形固定为电压原始值 2048、电流原始值 2748。这是合成数据，不代表实际模拟输入。

测试：`python -m unittest discover -s tests -v`。Windows 桌面测试：`python tools/v26_gui_smoke.py`。协议文档与设计/实施计划位于 docs。
