# AD-HOST 0.6.4 · Qt6 / MVC

完整解压便携包，运行 AD-HOST.exe。窗口右上显示连接状态，顶部设置 IP、端口和保存目录；采集、记录、诊断分别位于三个页签。

采集流程：连接 → 设置记录窗口及触发 → 准备采集 → 手动触发或等待阈值 → 暂存并查看 → 确认保存存档。版本号、设备标识和时钟固定值检查仍停用。详细协议操作见 V26_QUICKSTART.md。

## V28 保存采样率

在“采样窗口”的“保存采样率”输入 1–100 MSPS 的整数，默认 100。与其他参数一起点击“应用配置”或“准备采集”，两者都会提交完整的 11 参数配置，包含当前输入的速率，无需单独设置按钮。采集中或自动重复期间配置输入禁用。

输入框是待提交值；旁边的“设置 / 本次”是设备回读值。设置失败时请查看状态和诊断，不能把输入值当作设备已生效值。

保存采样率与 ADC 时钟不同：ADC 和触发检测仍为 100 MHz。时间模式 N=毫秒数×MSPS×1000；点数模式 N 保持不变、记录时长随速率变化。例如 2 ms、5 MSPS 为 10,000 组、80,000 HEX 字节，30% 前触发为 3,000 组。

HEX 同名 JSON 保存 ACTIVE_RATE_MSPS、原始 RATE 时钟及 TRIGGER_DELAY_TICKS / TRIGGER_PHASE。波形与光标使用记录本身的锁存保存速率，不使用当前界面的输入值，也不把 RATE=100000000 当成 V28 的保存速率。V28 以 ACTIVE_PRE 对应的保存边界为零点，按保存速率绘制名义时间；原始触发相位字段尚无换算规则，不作精确物理触发时间补偿。

只打开 HEX 而缺少 JSON 时无法推断保存速率，会提示按 100 MSPS 从记录起点计时；低速率记录请保留 HEX 与同名 JSON。旧 V26 记录仍按 100 MSPS 打开。

不按 VER 字符串拦截连接。设备有 CFG_RATE_MSPS 字段时启用速率设置并使用 11 参数配置；旧设备缺少速率字段时仍可按 100 MSPS 使用 10 参数配置，低速率请求会提示不支持。诊断输入支持 RATE n 及 10/11 参数 CFG、ACQ；V28 的 10 参数形式明确恢复到 100 MSPS。

协议来源：[V28 对接说明](protocol/V28_协议指令与上位机开发说明.md)。模拟运行：`python tools/v26_simulator.py --v28`；界面验证：`python tools/qt_smoke.py --v28`。

## 采集设置与光标读数

采样窗口按“设置方式 / 每通道采样时间或点数 / 触发前占比”分列显示，下面设置保存采样率。输入框直接显示 ms、点、% 单位，旁边显示触发后占比；下方摘要显示实际点数、时长以及触发前后点数。阈值条件每通道一行，对齐显示通道、比较关系、ADC 阈值和说明；两路阈值旁加亮显示实际电压 V / 电流 A。手动触发模式下隐藏通道选择、比较关系、阈值和阈值说明；切换回自动模式恢复显示并保留原来的值。

波形底部为固定读数表：鼠标位置、光标 A、光标 B、差值 B−A 各一行，按采样点、时间 ms、电压 V、电压原始 ADC 计数、电流 A、电流原始 ADC 计数分列；A/B 颜色与曲线标记一致。两路原始计数直接读取原始样本，B−A 同时显示有符号的电压、电流及 ADC 计数差。差值保留正负号，未设置的光标显示“—”，切换或清除记录会清空读数。

采集操作按钮固定在页签底部；窗口较小时可滚动参数区，操作按钮仍可见。

## 暂存、查看与确认存档

连接和采集不在正式存档位置创建目录。Qt 上位机将收到的数据和 JSON 元数据写入系统临时目录，继续采用后台接收和有界写盘队列。临时数据不是正式存档，不应依赖它长期保存。

在“记录与波形”页选择列表中的记录，可先查看波形，再点击“保存选中记录”。在目录选择框确认目标位置后，才创建正式存档。取消选择不会产生任何存档。默认位置为“文档/AD-HOST”，不再使用 captures。每条记录独立存档，目录及 HEX 名称均为 `YYYYMMDD_HHMM`；同一分钟依次使用 `_1`、`_2` 等后缀，已有目录永不覆盖。名称使用确认保存时的本地时间，采集时间仍保存在 JSON 中。

HEX 和同名 JSON 成对复制到存档中，保存失败可重试，原暂存记录保持不变。复制在后台进行，界面不会因为大文件保存而阻塞。断开或重连不会清空本次软件运行中的记录列表；重复采集得到的每条完整记录均可单独选择。已保存记录可继续查看，无需重复存档。

关闭软件时，如仍有未保存记录或采集正在进行，会提示取消关闭或放弃暂存数据。正常退出会先停止接收、关闭波形读取线程、等待正在进行的存档完成，再清理临时文件。异常退出时系统临时目录可能留有文件，软件目前不提供跨进程恢复列表。旧版已保存的 HEX/JSON 仍可直接打开。

## 波形查看

- 在“记录与波形”打开已完成的 HEX，或选择本次采集记录。HEX 和同名 JSON 一起保存可恢复触发时间。
- **拖动**：在曲线区域按住左键平移；两通道时间轴联动。
- **滚轮**：以鼠标位置为中心放大/缩小时间轴；**框选放大**可直接选择区域。
- **全貌**：恢复整个记录和纵轴范围；**触发位置**：回到以触发为中心的时间窗口。有元数据才提供触发位置。
- **纵轴适应**：按当前可见数据调整纵轴；也可以输入采样点范围，终点不包含在内。
- 移动鼠标显示最近原始采样点的时间、电压 V、电流 A 及两路 ADC 计数。
- **双光标**：切换测量模式，选择 A/B 后点击曲线；按住已有标记可拖动。读数显示 B−A 的时间差、点数差、电压差、电流差及两路计数差。
- **保存图片**：导出当前视图和可见测量标记为 PNG。

大范围曲线为保留峰谷的概览，放大后重新从原始数据生成。光标读原始样本，不读抽稀曲线。保存 100 MSPS 对应每点 10 ns，5 MSPS 对应每点 200 ns。

解析在后台运行，可取消；窗口关闭时取消任务并释放数据。软件退出时先停止 TCP 接收并等待文件关闭。超大文件仍沿用原有 1 GiB ASCII 输入上限。

## 目录结构

```text
src/
  app.py                    应用组装与入口
  models/                   协议、TCP 会话、写盘、文件解析、原始样本计算
  controllers/              采集操作、异步波形任务、交互调度
  views/                    主窗口、波形窗口
    widgets/styles.py       通用 GLOBAL_STYLE 与阈值高亮样式
    widgets/theme.py        本项目样式补充与 QtAwesome 图标
    widgets/controls.py     通用按钮、卡片、输入控件
ad_host/                    旧模块导入兼容及历史 Tk 界面参考
tests/                      模型与生命周期测试
tools/qt_smoke.py            Qt 采集/绘图/交互测试
```

Model 不依赖 Qt。View 不操作 socket 或读取数据文件。Controller 通过既有后台会话和波形工作线程组织任务，Qt/Matplotlib 只在主线程更新。UI 以 100 ms 周期读取采集快照；波形缩放请求延迟合并并仅保留最新任务，避免排队积累。

## TST 被拒绝时的诊断连接

若 TCP、VER、FST 正常但 TST 返回 `?` 或完整回包缺少必需字段，软件保留连接并进入“仅诊断”状态。此时不假定采样率为 100 MSPS，也不使用旧 TST 或 FST 数据启动采集。暂停自动轮询和重复采集；仍可查询 VER/FST/FREG/TST，FINIT 仅在用户主动发送时执行。断线、超时或不明确的收包边界仍结束连接，避免错配后续回复。

日志示例 `VER=V1.0.15 (V28)`，FST `VER:1000,INIT:0,IERR:4` 表示 STM32 可通信，但 FPGA 初始化报告版本不匹配。V28 对接说明期望 FPGA VERSION `0201`。应核对 FPGA 实际烧录程序及 FMC 版本寄存器读值；不能仅凭这份日志区分未烧录配套 FPGA 与寄存器读取异常。上位机的版本严格检查保持停用，不能绕过设备自身拒绝命令的问题。

设备恢复后点击诊断页 TST，取得有效状态即恢复采集操作。不会自动重启上一轮采集；请重新准备采集。

## 电压与电流换算（0.6.3）

两通道为 12 位无符号 ADC，零点 2048；ADC 输入为 `(raw×2/4096−1) V`。运放缩小 6 倍，SMA 电压为 ADC 输入×6。电压探头缩小 5000 倍，所以实际电压 `V=(raw×2/4096−1)×30000`；电流探头每 40 A 对应 SMA 1 V，所以实际电流 `A=(raw×2/4096−1)×240`。

例如 raw=3072 时 ADC 输入 0.5 V、SMA 3 V，对应电压 15000 V、电流 120 A。每个计数对应 14.6484375 V、0.1171875 A；这是量化步长，不代表仪器精度。raw=0 / 4095 分别对应 −30000 / 29985.3515625 V 和 −240 / 239.8828125 A。

两路阈值默认均为 2048，对应 0 V、0 A。阈值仍输入原始 ADC 计数，协议发送值不变；旁边仅以 NORD8 字色显示实际阈值，不改变背景。波形、鼠标读数和 A/B 差值统一按上述倍率换算，原始 HEX 不变。旧记录也使用当前确认的探头倍率重新显示；两路超过 4095 的样本会报错，不截断、不掩码。

新记录 JSON 中附带换算参数。诊断页集中显示完整设备状态、传输计数、换算参数、当前波形元数据和详细错误；操作页仅显示简短提示。

## 诊断回包与日志（0.6.4）

输入 VER、FST、TST、FREG 可查询设备，支持大小写及首尾空格；按钮与输入框共用同一串行处理。输入框不必手动填写回车，也不接受多条指令。发送成功后清除先前的输入错误提示；主机未发送与设备返回 ? 会明确区分。

日志记录手动查询的“发送 / 接收”及实际回包。后台自动 TST 仅更新状态快照，不重复刷入事件列表。停在日志底部时跟随最新内容；向上查看历史或选中文本时暂停替换日志，保留正在阅读的内容；回到底部并取消选择后显示最新内容。
